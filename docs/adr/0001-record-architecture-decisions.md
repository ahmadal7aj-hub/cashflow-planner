# ADR 0001: Record architecture decisions

- Status: Accepted
- Date: 2026-10-01

## Context
The BRD requires an ADR for every material technical decision, and coding agents need durable context.

## Decision
Keep one short Markdown file per decision in `docs/adr/`, numbered sequentially (`NNNN-title.md`) with Status, Context, Decision, Consequences.

## Consequences
Decisions are reviewable in PRs and traceable. Initial stack (BRD section 10) will be recorded in ADR 0002.
